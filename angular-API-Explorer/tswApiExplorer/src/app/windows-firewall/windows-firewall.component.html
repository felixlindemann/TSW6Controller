Windows Firewall – API-Freigabe

Port-Freigabe für TSW6 API

Damit der TSW6 Controller mit dem TSW6-Server auf Ihrem Windows-PC kommunizieren kann, muss der Port 31270 in der Windows-Firewall geöffnet werden.
Darüber hinaus muss die engine.ini-Datei von TSW6 angepasst werden, um den API-Zugriff von anderen Geräten zu ermöglichen.
