Willkommen zum TSW6 Controller Web-Frontend

Was ist das?

Dieses Web-Frontend ermöglicht die komfortable Konfiguration und Steuerung des TSW6 Controllers über das Netzwerk. Sie können WLAN-Einstellungen, Server- und DNS-Konfiguration sowie weitere Optionen bequem im Browser anpassen.

Wie funktioniert es?
  1. Verbinden Sie Ihren PC oder Ihr mobiles Gerät mit dem WLAN des TSW6 Controllers oder dem gleichen Netzwerk.
  2. Öffnen Sie diese Seite im Browser (z.B. über die IP-Adresse des Controllers).
  3. Nutzen Sie die Navigationsleiste, um die gewünschten Einstellungen vorzunehmen.
  4. Speichern Sie Ihre Änderungen – der Controller übernimmt die Konfiguration automatisch.
Hinweise
  • Die Änderungen an WLAN, Server oder DNS werden direkt auf dem Controller gespeichert.
  • Ein Neustart des Controllers ist über die Navigationsleiste möglich.
  • Für die Verbindung zum TSW6-Server benötigen Sie den passenden TSW-API-KEY.
Tipp: Über die "Arduino-Konfig"-Schaltfläche oben rechts gelangen Sie zu allen wichtigen Einstellungen.
WINDOWS-Firewall

Damit der TSW6 Controller mit dem TSW6-Server auf Ihrem Windows-PC kommunizieren kann, müssen bestimmte Ports in der Windows-Firewall freigegeben werden. Nutzen Sie dazu die bereitgestellten Skripte, die Sie mit Administratorrechten ausführen sollten. Die ZIP-Datei enthält sowohl CMD- als auch PowerShell-Skripte zum Aktivieren und Deaktivieren des API-Zugriffs.

  • Entpacken Sie das ZIP-Archiv nach dem Download.
  • Führen Sie das gewünschte Skript per Rechtsklick als Administrator aus.
  • Die Skripte passen die Firewall-Regeln automatisch an.
